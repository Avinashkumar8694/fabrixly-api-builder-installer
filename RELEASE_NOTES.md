# Loom Studio 0.4.0

The desktop app of Loom, the API builder. Build, test and run services on your own computer; browse and install nodes, libraries, middleware, services, APIs and data models from the marketplace; publish with your Fabrixly account.

Pick the file for your system (the table in the [README](https://github.com/Avinashkumar8694/fabrixly-api-builder-installer#download) says which), install it, and sign in. Every file's SHA-256 is in `SHA256SUMS`.

* macOS: `.dmg` (Apple silicon: `arm64`, Intel: `x64`)
* Windows: `Setup-…-x64.exe` for most PCs
* Linux: `.AppImage` (runs anywhere) and `.deb`

The apps are not signed yet (see the README, "First start").
